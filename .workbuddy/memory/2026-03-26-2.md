# 2026-03-26（下午） - 番外发布功能集成到章节页面

## 需求
把「发布番外」按钮放到主线页和分支页的章节页面中，方便用户在阅读故事后快速创作番外。

## 实施内容

### 1. 后端数据层增强
- **storyController.ts**：`getStoryById` 新增 `spinoffs` include，包含 author 信息，按创建时间倒序
- **branchController.ts**：`getBranchById` 新增 `spinoffs` include，包含 author 信息，按创建时间倒序

### 2. 前端接口更新
- **storyService.ts**：
  - `Story` 接口增加 `spinoffs?: Spinoff[]`
  - `Branch` 接口增加 `spinoffs?: Spinoff[]`
  - 引入 `spinoffService`

### 3. 主线页番外展示（MainlinePage.tsx）
- 概览 Tab 左列新增「番外作品」区块：
  - 顶部显示番外数量徽章
  - 登录后显示「发布番外」按钮（右上角）
  - 番外列表显示：图标（官方/非官方区分）、标题、作者、日期
  - 空 state：Sparkles 图标 + 暂无番外提示 + 创建第一个番外按钮
  - 超 5 个时显示「查看全部 X 个番外作品」按钮
- 新增 `isSpinoffModalOpen` 状态和 `newSpinoffData` 状态
- 新增 `handleCreateSpinoff` 函数，调用 `spinoffService.create`
- 新增「发布番外作品」Modal（标题+内容，带引导文案，主题色 amber）

### 4. 分支页番外展示（BranchPage.tsx）
- Header 区域新增横向滚动番外展示区：
  - 橙色渐变背景（from-amber-50 to-orange-50）
  - 左侧显示番外数量徽章
  - 登录后显示「发布番外」按钮
  - 番外卡片横向滚动（w-64 固定宽度，flex-shrink-0）
  - 空 state：居中 Sparkles 图标 + 暂无番外提示
- 新增 `isSpinoffModalOpen` 状态和 `newSpinoffData` 状态
- 新增 `handleCreateSpinoff` 函数，调用 `spinoffService.create`
- 新增「发布番外作品」Modal（与主线页一致）

## 设计亮点
- **主线页**：番外作为概览区的独立区块，与平行宇宙并列，层级清晰
- **分支页**：番外作为 Header 的横向滚动区，不占用过多空间
- **交互**：番外卡片 hover 效果，官方/非官方用不同颜色区分
- **空状态**：引导性设计，鼓励用户创作
- **权限控制**：发布按钮仅登录后显示，未登录用户只能浏览
