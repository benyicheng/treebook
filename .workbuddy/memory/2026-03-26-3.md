# 2026-03-26 工作日志（第三部分）

## 修复：分支页番外查询 500 错误

**问题**：访问分支详情页时返回 500 错误。

**原因**：Prisma schema 中 `Branch` 模型没有与 `Spinoff` 的直接关系。`Spinoff` 只关联到 `Story`（`originalStory`），所以不能在 `getBranchById` 中直接查询 `spinoffs`。

**修复方案**：
1. **后端**：`branchController.ts` 的 `getBranchById` 改为通过 `parentStory.spinoffs` 获取番外列表
2. **前端**：`BranchPage.tsx` 中所有 `currentBranch.spinoffs` 改为 `currentBranch.parentStory?.spinoffs`
3. **类型**：`storyService.ts` 中 Branch 接口移除 `spinoffs` 字段，在 `parentStory` 类型中声明 `Story & { spinoffs?: Spinoff[] }`

**影响范围**：
- `api/src/controllers/branchController.ts`
- `src/pages/branch/BranchPage.tsx`
- `src/api/storyService.ts`

**结果**：分支页现在可以正常访问并展示番外作品了。
