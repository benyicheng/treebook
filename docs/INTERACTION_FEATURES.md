## 5. 防刷机制

### 5.1 限流策略

| 操作 | 限制 | 窗口 | 违规阈值 | 封禁时长 |
|------|------|------|----------|----------|
| 点赞 | 30次 | 1分钟 | 5次 | 5分钟 |
| 评分 | 20次 | 1分钟 | 3次 | 10分钟 |
| 分享 | 60次 | 1分钟 | 10次 | 3分钟 |
| 查看统计 | 100次 | 1分钟 | 20次 | 5分钟 |

### 5.2 防刷检测规则

1. **高频操作检测**: 同一目标1分钟内操作超过5次
2. **多目标刷量**: 1分钟内操作超过20个不同目标
3. **时间模式检测**: 请求间隔过于规律（方差<100ms）
4. **设备指纹识别**: 基于IP+UA生成唯一标识

## 9. API文档

### 9.1 获取互动统计

```http
GET /api/interactions/:targetType/:targetId
```

响应:
```json
{
  "success": true,
  "data": {
    "targetType": "story",
    "targetId": "xxx",
    "likeCount": 100,
    "shareCount": 50,
    "ratingCount": 30,
    "ratingAvg": 4.5,
    "ratingDist": {
      "10": 5,
      "9": 10,
      "8": 15
    },
    "liked": false,
    "myRating": null,
    "myReasonTags": []
  }
}
```

### 9.2 点赞/取消点赞

```http
POST /api/interactions/:targetType/:targetId/like
Authorization: Bearer <token>
```

### 9.3 提交评分

```http
PUT /api/interactions/:targetType/:targetId/rating
Authorization: Bearer <token>
Content-Type: application/json

{
  "score": 4.5,
  "reasonTags": ["剧情精彩", "人物立体"]
}
```

### 9.4 记录分享

```http
POST /api/interactions/:targetType/:targetId/share
Content-Type: application/json

{
  "platform": "wechat"
}
```
