# 功能验收清单（内容审核）

## 门禁
- Code Review：至少 1 位 reviewer 完成审核并通过
- QA 回归：覆盖核心写入链路（故事/章节/评论/番外/书单/AI）
- 灰度验证：按用户/业务线灰度，观察无异常后再逐步放量

## 功能
- 文本审核
  - 章节标题/内容：创建与更新均会产生审核任务与结果
  - 评论内容：创建会产生审核任务与结果
  - 故事标题/简介、书单标题/简介、番外标题/简介/内容：创建与更新均会产生审核任务与结果
- 媒体审核（URL）
  - 故事封面/书单封面/角色头像：写入后产生审核任务
  - AI 生成图片/视频：prompt 与结果 URL 均产生审核任务
- 管理后台
  - `/admin/moderation` 能展示近 1h/6h/24h/7d 指标
  - 管理 API 可导出报告（JSON/CSV）
  - 管理 API 支持人工覆盖决策并写入审计日志

## 稳定性
- 审核队列表不存在/数据库异常时：业务写入不受影响（旁路吞掉异常）
- provider 超时/异常：不会阻塞接口响应，worker 按退避重试并可熔断
- worker 停止运行：业务写入仍正常，审核任务堆积可通过仪表盘与 metrics 发现

## 性能
- 业务写入接口延迟增量：enqueue 旁路调用不 await，P95 无明显上升
- worker 吞吐：在目标并发下 jobs 积压不持续增长

## 可观测性
- metrics 接口返回按状态/提供方/对象的聚合数据
- decisions 列表可用于问题追踪（traceId 可关联请求链路）

## 灰度与回滚
- 灰度：配置 `moderationConfig.rollout` 后立即生效（缓存 TTL 30s）
- 回滚：将 `moderationConfig.mode=off` 后 5 分钟内验证异常消失
